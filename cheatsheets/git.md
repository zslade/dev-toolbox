# Git Cheatsheet

## History/log

```bash
git log --oneline --graph --decorate -5 # print a  visual summary of the last 5 commits in project's history
git diff --staged
```

## Daily shortcuts

```bash
git status
git add -A # includes changes within all sub directories
git commit -m "message"
git pull # or
git pull --rebase
git push
```
